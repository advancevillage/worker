# 教材下载与点读资源

使用技能目录下 `scripts/` 的独立脚本完成任务。运行数据存入单独的工作目录，不写入技能目录。当前实现面向 macOS、Google Chrome、Python 3.11+、Node.js 和 Apple Vision OCR。

## 选择入口

- 下载教材、登录及分步处理：读 [操作流程](references/workflow.md)。先明确学科、年级、版本、册次；目录同版同册存在多个年度时再确认年度，不根据城市擅自猜版本。
- 点读内容、页码索引、翻译或校验：读 [数据协议](references/protocol.md)，结构以 `scripts/schemas/` 和 `scripts/readalong.py` 校验器为准。
- 图片清晰度、旧 JPG 迁移或预览修改：读操作流程中的“迁移与预览”。
- 气泡内容范围、曲线或边界质量修正：读 [轮廓与视觉验收](references/contour-quality.md)。几何校验与点击通过不代表轮廓贴合。

## 核心约定

1. 默认从原 PDF 以 300 DPI 重新生成 PNG；把已有 JPG 改后缀不能改善清晰度，PNG 也无法恢复 PDF 中已缺失的细节。
2. 封面和正文按照本流程各做两轮真实 TinyPNG 上传下载，一图一个 tab、复用同一浏览器；后轮上传前轮结果。上传到第三方须在本次任务授权范围内。用户只要求下载 PDF 时不要附加压缩或点读工作。
3. 完成压缩后计算 `pid = 最终原图字节 MD5 + 实际后缀`，如 `<md5>.png`。译文 `trans/<pid>` 复用原图 pid，不能用译文自身哈希命名。
4. 书页索引使用八种确定分类，正文按印刷页码查找。物理页只用于内部 PDF 映射，最终协议不输出物理页。分类、页码、内容不明确时产生 tell-me，带上具体待确认项；不填 unknown/other。
5. 每页 `areas` 是扁平列表，每项只有 `polygon` 和完整 `edurich`。语言只允许 zh/en。页码不作为点读内容，题号、公式数字与页脚正文不能误删。
6. 坐标须基于最终图片尺寸。对话框、对话气泡和思考气泡只标注实际内容区域：连续多行文字按自然文本块圈选，保留少量阅读内边距，不逐字描边；排除大块空白底色、外框、尾巴及分离尾圈，不为这些装饰单独建area。气泡内有教学意义的图标按实际内容保留，仅在语义连续且不会包入大块空白时与文字合并，不能仅因共用气泡而合并。 独立标题、标签底板可沿底色外边界标注；此规则不用于扩大气泡点击范围。保留的教学插画沿语义完整外边界，圆圈题号沿外圈独立标注。合并保留EduRich阅读顺序，图标用MD5命名的辅助图片保存。自动OCR和边界脚本只生成候选，人工核对后才设置reviewed；不得绕过哈希绑定或几何校验。详见[轮廓与视觉验收](references/contour-quality.md)。
单色装饰人物、动作剪影及页底装饰默认不建点读区域，不拆成头发、四肢等碎片；保留原图中的插画。承载题意、词义、人物身份或用户明确要求点读的插图可保留，不能仅凭颜色删除。

同页areas内部、trans内部分别两两检查：不得交叉、重叠、完全包含、重复、共边或共点。原图与译文两个列表不互相比较。相邻区域建议留1—2个最终图片像素的间隙。不能用图层排序或每个区域都能点到替代互斥校验；冲突必须修复后发布。

7. 先完成用户指定样本（通常一张封面、一张正文），确认质量后按授权处理整书。样本成功不代表整书完成；未完成内容不得发布整书索引。

## 执行与交付

按操作流程逐步执行，每步检查真实输出和退出码。需要登录时复用独立 profile，打开页面让用户登录，登录后继续。验证码、配额、未发生实际上传、无法访问的资源应暂停并报告；不无限重试。

默认最终目录为 `~/Downloads/教材/{年级}/{学科}/{上下册}/`。用独立暂存目录构建扁平输出，校验通过后再发布，替换旧资源前保留备份。不能把两页样本目录直接覆盖整本教材目录。保持已有 PDF 和 meta 不变，除非任务包含更新。

交付具体预览链接、完成的册次或页码范围、验证结果及未完成项。预览左图右内容、坐标常显，数学使用本地 MathML 排版；截图采用正常窗口尺寸。

实现限制：未配置自动翻译服务；英文译文输入需核对；中文译文图合成仅支持已确认纯色矩形背景。复杂插画背景或不支持的 EduRich 节点需要确认方案，不能声称已自动完成。

压缩轮数默认2，可用`--rounds N`指定。旧任务保留原目标；显式变更用`--action set-rounds --rounds 2`，保留历史与备份，复用真实第2轮产物。迁移不解除暂停；限流解除后显式resume再run。旧五轮已发布资源无需回退。
