# 反馈

## 10 骨架退出
用途：加载未知内容时保持结构。

交互：内容就绪后交叉淡入，避免额外闪烁与占位跳动。

提示词：实现骨架过渡：加载时轻微呼吸，内容就绪后骨架淡出、内容轻微上移淡入，保持占位稳定。快速加载不闪屏，失败显示重试，不额外闪烁。

## 13 下拉刷新
用途：有真实刷新动作的列表。

交互：越过阈值箭头翻转，释放触发刷新；加载期间不重复请求。

提示词：实现下拉刷新：拉过阈值箭头翻转，松手转为加载，成功短显示“已更新”后收起，失败提示重试。未过阈值回弹，不与分页或面板拖动冲突。

## 18 顶部Toast
用途：无需操作的短确认。

交互：从安全区内进入，短暂停留后退出；需要处理的错误用持久提示。

提示词：实现顶部Toast：从状态栏安全区下方短距离落入，默认停留两秒后收回，支持手动关闭。重复提示合并，不抢焦点；需用户处理的信息使用持久提示。

## 22 对话气泡
用途：连续消息流。

交互：只对新消息入场；底部阅读跟随，历史阅读保持位置。

提示词：实现对话气泡：新消息从底部轻微上移淡入，流式更新不重复入场。用户在底部时平滑跟随，阅读历史时保持位置并显示最新消息入口；容器内滚动。
