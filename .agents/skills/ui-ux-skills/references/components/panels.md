# 面板

## 1 撕线面板
用途：带轻量趣味的补充内容展开。

交互：虚线提示拖动，下拉露出内容；释放后按阈值展开或收起，另设点击入口。

提示词：实现撕线展开面板：底部虚线把手可点击或下拉，内容随拖动露出；超过阈值展开，否则松手回弹。取消恢复，长内容可滚动。

## 5 照片抽屉
用途：图片预览与相关信息同屏展示。

交互：照片占上方，底部面板升起；上拖时照片缩小，面板分档停靠。

提示词：实现照片抽屉：打开时照片展示在上方，信息面板从底部升起；上拖面板时照片连续缩小。面板按档位吸附，内部滚动与拖动分开，支持关闭和返回。

## 9 上下文菜单
用途：列表项的次级操作，不替代关键入口。

交互：长按显示菜单；拖动释放仅在有效项上选定，外部取消；支持点选。

提示词：实现长按上下文菜单：浮出轻磨砂菜单，图标短淡入；按住滑到有效项后松手选定，也支持点击。边缘自动避让，外部点击取消，不与原有长按手势冲突。

## 21 折叠面板
用途：按需展示次级信息。

交互：标题整行可点击，高度与箭头同步变化；收起内容不可聚焦。

提示词：实现折叠面板：点击标题后内容平滑展开，箭头同步旋转。快速重复点击从当前状态衔接，动态内容不裁切，收起内容退出焦点与辅助阅读。
