# 导航

## 4 轮播指示
用途：表达连续分页的位置。

交互：相邻点随页面偏移伸缩；单页隐藏，多页限制可见点数。

提示词：实现轮播指示点：当前点拉长，拖动时相邻点连续伸缩，松手随页面吸附。支持按钮翻页，单页隐藏指示器，多页避免溢出。

## 8 日期条
用途：按日期查看已有内容。

交互：选中底色滑动，左右翻周，月份从当前日期同步；禁用日期清晰区分。

提示词：实现横向日期条：选中底色平滑移到目标日期，左右滑动翻周，月份同步当前选中日期。支持跨月跨年、返回今天和禁用日期，翻周不隐式修改选择。

## 14 Tab栏
用途：切换平级主页面。

交互：选中图标轻微上移，指示器横移；非选中项保持可读。

提示词：实现Tab切换：选中图标轻微上移并强调，指示器滑到对应位置。非选中项保持清晰，快速切换结果一致，保留各页状态与安全区。

## 16 层叠轮播
用途：浏览可逐张查看的卡片。

交互：顶层拖动露出下层，释放按阈值切换或恢复；卡片滑走不代表删除。

提示词：实现三层卡片轮播：拖动顶卡时下层逐渐显露，松手按距离或速度切换，否则回位。提供前后切换按钮，明确首尾行为，滑走不删除数据。

## 17 搜索扩展
用途：已有搜索功能的紧凑入口。

交互：点击展开输入框并聚焦，取消入口同步出现；键盘不遮挡结果。

提示词：实现可展开搜索框：点击放大镜扩展到可用宽度并聚焦，取消按钮滑入。输入防抖，忽略过期结果；取消关闭键盘并恢复原视图，覆盖空结果和失败。
