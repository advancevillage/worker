# 动效与手势

## 共享规则

- 沿用项目颜色、字号、圆角与组件形态。动效表达操作、层级或真实状态，不延迟业务完成。
- 建议起点：按压80ms、恢复150ms、状态150–200ms、布局200–300ms；以预览调整，不作为硬性标准。
- 按压轻微缩放至0.98，或收起现有实体阴影并位移；两种效果不叠加。取消、失焦和禁用均恢复。
- 普通过渡用ease-out；弹性只用于轻量释放反馈，避免大幅过冲。拖动直接跟手，松手才缓动。
- 保持动画前后的布局占位稳定。减少动态效果时关闭位移、弹跳和循环，保留即时状态或短淡入。

## 输入与状态

- 优先平台手势阈值。区分点击、拖动与长按；拖动取消不提交，父子滚动各自职责明确。
- 隐藏手势提供可见入口；触控区按平台规范，移动端建议至少48×48逻辑单位，并与安全区保持距离。
- 状态不能只靠颜色表达。补充可访问名称、选中/展开/禁用状态；支持平台适用的键盘与辅助操作。
- 加载、成功、失败由真实数据驱动；无比例用不定进度，不伪造百分比。防重复提交，失败可恢复或重试。
- 新操作中断旧动画时从当前视觉状态衔接。异步结果按请求身份处理，忽略过期回调。
- 离屏或后台暂停循环动画；销毁释放控制器、监听和定时器，避免页面关闭后更新状态。

## 验收

检查快速重复操作、慢拖与取消、首尾/上下限、加载失败、空内容、安全区、大字号和减少动态效果。重点验证结果与手势冲突；纯视觉参数通过预览调整，真实触感与音频用设备确认。
