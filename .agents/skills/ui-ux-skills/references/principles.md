# UI/UX 设计原则

## 工作方式

明确场景、目标用户与关键操作 → 沿用或确定视觉样式 → 定义状态与边界 → 选择交互 → 给出可观察的验收标准。现有产品优先补反馈与一致性，不为展示动效增加功能。

## 十大设计原则

**1. 创新性 Innovative** — 真正解决问题，而非跟风堆砌
- 创新来自用户真实痛点，不是视觉噱头
- 宁可不做，不做平庸的创新

**2. 实用性 Useful** — 提高效率，不占用时间
- 每个功能必须回答：给用户带来了什么价值？
- 无法说清价值的功能，砍掉

**3. 美学性 Aesthetic** — 符合并引导审美，不落伍于时代
- 视觉语言统一，美感来自比例、留白与秩序
- 不因用户抱怨而停滞迭代

**4. 易用性 Understandable** — 零学习成本，润物细无声
- 用行为引导替代文字说明
- 好的设计让用户感知不到设计的存在

**5. 克制 Unobtrusive** — 不用干扰换曝光
- 拒绝节日换肤、开屏广告、强推通知
- 增加每个元素前先问：去掉它会怎样？

**6. 诚实 Honest** — 理性的善良，不套路用户
- 不用暗模式诱导操作，错误提示清晰不甩锅
- 盈利是做好产品的副产品，不是目的

**7. 耐用性 Long-lasting** — 核心形态稳定，经得起时间考验
- 勇于改变需要改变的，克服害怕改变的
- 交互范式保持稳定，让用户建立长期信任

**8. 细节极致 Thorough** — 内在一致，不放过任何角落
- 间距、字号、颜色有系统规范
- 空状态、错误、加载等边界状态同样精心设计

**9. 无害 Environmentally Friendly** — 不以体验损耗换商业收益
- 评估每个功能对用户时间与注意力的消耗
- 平台健康优先于短期流量

**10. 极简 Less is More** — 减无可减，才是好设计
- 功能、界面、流程同步做减法
- 无法决定是否去掉某功能时，答案通常是去掉

## 产品哲学

**原动力决定产品上限**
产品需要有明确的使命，所有决策围绕使命展开。没有使命的产品只会追逐流量，流量耗尽，游戏结束。

**自然增长验证产品力**
新产品在获得自然增长曲线之前，不应强推。用户自发传播是唯一有效的产品力证明。

**独裁保护产品灵魂**
好产品需要清晰的认知主导，过度民主会让产品四分五裂、失去性格。决策遵循好的设计原则，而不是投票。

**创造者与用户共赢**
平台的生命力来自让创造者体现价值。只让自己好、不让别人好的事，通常不会长久。

**创新是应对未来的唯一办法**
时代更迭加速，三五年就是一个时代。找到并面对未来的需求，比守住现有用户更重要。

---

## 技术与AI

好的技术为产品服务，AI 应默默躲在后面帮助用户，而不是作为卖点炫耀。技术无感知地提升体验，才是最高境界。不跟风做 AI，而是让 AI 落地到真实的功能和场景。

## 交付约定

按用户请求交付方案、提示词或实现，遵循已有授权。复杂改动先说明范围与取舍；需要补充信息时只询问影响结果的内容。
