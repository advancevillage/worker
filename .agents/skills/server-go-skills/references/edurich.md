# EduRich 教材排版协议

状态：`0.1.0-draft`，供评审与探索，不是已验证或冻结的 1.0 标准。

EduRich 定位为中小学教材内容、排版和交互语义的跨端协议；EduMath 等为子模块。Flutter/Web 消费同一份文档，具体组件、渲染引擎和服务端语言不属于协议。

## 按需读取

- 定义或评审协议字段、模块边界和兼容策略：[标准与约定](edurich/standard.md)。
- 编写图文公式内容或核对字段含义：[协议示例](edurich/examples.md)。
- 讨论易用性、可用性、扩展性、维护性和遗漏：[评估与待决事项](edurich/review.md)。

## 使用约定

当前技能提供标准与约定，不默认生成代码、接口或正式 Schema。先区分草案约定、候选能力和已验证结果；新增字段同步说明类型、合法位置、默认值、失败行为及兼容影响。保留用户选择的模块边界，不将特定渲染器支持范围当成协议保证。

评审先核对阅读顺序、节点合法位置、资源与公式的单一事实来源，再讨论视觉细节。任何概念图均需标注其不是实际协议渲染结果；未做双端验证的能力不得标为跨端兼容。
